## 1. Диагноз (текущее состояние)

### 1.1 Поисковая видимость (GSC, 28 дней: 20.06–18.07.2026)

| Метрика | Значение | Оценка |
|---------|----------|--------|
| Показы | **907** | Низкий объём, ниша узкая |
| Клики | **15** | Критично мало |
| CTR | **1,7%** | Ниже нормы для бренда + коммерции |
| Средняя позиция | **~25** | Страница 2–3 у коммерческих запросов |

**Что видно по запросам:**

- Брендовые («крашеная доска», «крашенная доска») — позиции **3–9**, почти все клики.
- Коммерческие («вагонка крашеная купить», «крашеный планкен», «доска крашенная купить») — показы есть, позиции **30–50**, **0 кликов**.
- Локальные («крашеная доска истра») — топ-3, но CTR ≈ 0 (слабый сниппет / title).

**Что видно по страницам:**

| Страница | Показы | Клики | Поз. | Проблема |
|----------|-------:|------:|-----:|----------|
| `/` | 509 | 13 | 16 | Забирает почти весь трафик |
| `/krashenyj-planken/` | 146 | 0 | 36 | Пустой/слабый сниппет, нет CTR |
| `/katalog/` | 67 | 0 | 24 | Нет коммерческого оффера в meta |
| `/skandinavskaja-doska/` | 74 | 0 | 22 | Далеко от топ-10 |
| `/parketnaja-doska/` | 52 | 0 | 10 | Близко к кликам — приоритет CTR |
| `/uslugi/` | 37 | 0 | 4 | Хорошая позиция, нужен CTR |

**Вывод:** сайт почти не получает небрендовый спрос. Проблема не в «отсутствии индексации», а в **слабых коммерческих лендингах, дублях блога, плохих сниппетах и техническом долге Elementor**.

### 1.2 Ключевые проблемы (сводка аудита)

| # | Проблема | Влияние | Где чинить |
|---|----------|---------|------------|
| 1 | 13 из 16 постов блога — near-duplicate с одинаковым текстом; 2 поста пустые | Дубли, размытие веса, вред E-E-A-T | WP сейчас + `content/blog` в Next |
| 2 | Misleading slug (`…vosstanovlenie-polov…` у статей не про полы) | Низкий CTR, путаница | Консолидация → 301 |
| 3 | 2–3 H1 на страницах (Elementor) | Размытие релевантности | Шаблоны / Next |
| 4 | Пустые или заспамленные meta description | CTR = 0 при показах | Yoast / `seo` в JSON |
| 5 | `cache-control: no-store` + PHPSESSID | Скорость, CWV | Кэш / переход на SSG |
| 6 | Нет Product / LocalBusiness schema | Rich results, локаль | Разметка |
| 7 | Дубли URL: `/category/…`, `/katalog/…`, корневые лендинги (`/krashenyj-planken/`) | Каннибализация | Canonical + 301 |
| 8 | Миграция Next.js меняет URL (`/blog/` vs `/blog-post/`, `/katalog/x/` vs `/x/`) | Риск потери текущих позиций | Карта редиректов |
| 9 | Нет цен / оффера на лендингах vs конкуренты (LesLab, ЦветЛес, КрасимДоски) | Проигрыш в SERP и конверсии | Контент + UX |
| 10 | Аналитика в Next `settings.json` пустая | Нельзя мерить | Метрика / GA |

### 1.3 Конкурентный контекст

Сильные игроки Москвы: **LesLab, ЦветЛес, КрасимДоски, ArtWood, СеверЛес**. У них:

- цены «от … ₽/м²» в title и H1;
- отдельные посадочные под профиль (штиль, планкен, имитация);
- акцент на заводской линии, сроках 3–7 дней, каталогах RAL/NCS.

Наше УТП, которое нужно вынести в SEO: **запатентованный бренд + дилер Sirca + 11-шаговый цеховой цикл + производство в Истре**.

## 4. Трек A — Технический SEO

### A1. Срочные правки на текущем WP (до миграции)

| # | Действие | Критерий готовности |
|---|----------|---------------------|
| 1 | Один H1 на всех шаблонах Elementor; убрать placeholder «Главный заголовок h1» | Аудит: 1 H1 / URL |
| 2 | Meta title ≤ 60 симв., description 140–160 на: главная, каталог, все товарные лендинги, услуги, контакты | Нет пустых desc; нет `&quot;` |
| 3 | Включить кэш (WP Super Cache / nginx) — убрать `no-store` для гостей | HTML отдаётся с cache headers |
| 4 | Canonical: товарные лендинги → канон в корне (`/krashenyj-planken/`); `/category/…` → noindex или 301 на лендинг | Нет дублей в GSC «страницы» |
| 5 | Schema: `LocalBusiness` / `Organization` с адресом Истра + телефоном; `Product`/`Offer` на лендингах (хотя бы `AggregateOffer` «цена по запросу») | Rich results test OK |
| 6 | `robots.txt`: убрать Bitrix-правила если ещё есть; оставить WP + Clean-Param для Яндекса | Только актуальные Disallow |
| 7 | Закрыть от индекса: `author`, `uncategorized`, tag-архивы с тонким контентом | sitemap без мусора |

### A2. Карта URL при миграции на Next.js (критично)

Сейчас в индексе живут **корневые** лендинги и `/blog-post/…`. В Next заложены `/katalog/…` и `/blog/…`.

| Текущий URL (WP, в индексе) | Next (как в коде) | Решение |
|-----------------------------|-------------------|---------|
| `/krashenyj-planken/` | `/katalog/planken/` или аналог | **Сохранить корневые slug** ИЛИ 301 с корня → `/katalog/…` (лучше сохранить канон) |
| `/blog-post/{slug}/` | `/blog/{slug}/` | 301 `/blog-post/*` → `/blog/*` |
| `/category/vagonka/…` | нет | 301 на каталог/лендинг |
| `/uslugi/pokraska-…/` | совпадает | Оставить |
| Товары SKU в корне | `/katalog/{cat}/{sku}/` | 301 со старых permalink |

**Перед продом Next:** файл `_redirects` / nginx map со **всеми** URL из Yoast sitemap → новые каноны. Без этого миграция сожжёт текущие позиции.

Чеклист cutover:

1. Экспорт всех URL из `sitemap_index.xml`.
2. Таблица old → new (CSV).
3. 301 на сервере + canonical на новых страницах.
4. Отправка sitemap в GSC и Яндекс.Вебмастер в день релиза.
5. Мониторинг «Страницы с ошибками» 14 дней.

### A3. SEO в Next.js (кодовая база `site/`)

| Задача | Файл / зона |
|--------|-------------|
| JSON-LD Organization, BreadcrumbList, Product, FAQPage, Article | новый `lib/schema.ts` + layout/page |
| Уникальные `seo.title` / `seo.description` во всех JSON контента | `content/**` |
| Open Graph image (сейчас только title/desc) | `lib/metadata.ts` |
| `lastModified` в sitemap из дат контента, не `new Date()` | `app/sitemap.ts` |
| Яндекс.Метрика + GA ID | `content/settings.json` |
| Alt у всех изображений каталога/проектов | компоненты карточек |
| FAQ schema на `/tehnologija-…/` и услугах | уже есть FAQ UI |

### B2. Шаблон усиления коммерческого лендинга

Каждый товарный URL должен содержать:

1. **H1** с ключом + УТП («заводская покраска», «Москва / Истра»).
2. **Первый экран:** готово к монтажу · срок · породы · палитры.
3. **Цена:** хотя бы «от X ₽/м²» или «расчёт за 1 день» (как у конкурентов).
4. **Блок технологии** (кратко) + ссылка на `/tehnologija-nanesenija-kraski/`.
5. **Таблица:** порода / профиль / покрытие / сорт.
6. **FAQ** 5–7 вопросов (схема FAQPage).
7. **CTA:** Marquiz + форма + телефон.
8. **Внутренние ссылки:** смежные профили, палитра, 1–2 кейса `/project/…`.

Тексты «было → стало» для главной и ключевых страниц — в content-plan (часть C).

### B3. Блог: консолидация 16 → 10 канонов

Полная таблица 301 и ТЗ статей: [`knowledge/content-plan.md`](../knowledge/content-plan.md) (части A–B).

Очередь публикации через SEO-пайплайн (`briefs/` → `create article`):

| Очередь | Канон | Зачем |
|--------:|-------|-------|
| 1 | имитация бруса крашеная | Wordstat + коммерция |
| 2 | крашеный планкен для фасада | GSC-показы на `/krashenyj-planken/` |
| 3 | покраска деревянных фасадов | информационный мост к каталогу |
| 4 | заводская покраска пиломатериалов | УТП / отличие от конкурентов |
| 5 | бренд (обновление) | E-E-A-T |
| 6–10 | терраса, Sirca, доставка, сырьё, реставрация | покрытие кластеров |

После публикации — **301** со старых slug; удалить/не индексировать пустые `brend`/`dostavka` до переписи.

## 6. Трек C — Продвижение и спрос

### C1. Поисковые системы и локаль

| Канал | Действия |
|-------|----------|
| **Google Search Console** | Еженедельный разбор queries/pages; фиксация улучшений CTR; Indexing API / URL Inspection после релизов |
| **Яндекс.Вебмастер** | Добавить сайт (если нет), sitemap, Турбо не нужны; следить за «Безопасность» и ИКС |
| **Яндекс.Бизнес / Google Business** | Карточка: производство Истра + офис Мытищи, фото цеха, категории «Пиломатериалы», «Покраска» |
| **Яндекс.Метрика** | Цели: отправка формы, клик по телефону, Marquiz complete |

### C2. Внешний спрос (ссылки и упоминания)

Низкочастотная B2B/B2C-ниша — ссылки точечные, не «линкбилдинг пачками»:

1. Каталоги поставщиков стройматериалов (Москва/МО).
2. Партнёрские упоминания у дилеров ЛКМ (Sirca, BIOFA) — запросить listing.
3. Гостевые экспертные материалы: покраска фасада, сравнение масло/лак (с ссылкой на технологию).
4. Публикации кейсов проектов с фото «до/после» в профильных сообществах (без спама).
5. NAP-единообразие: название, адрес, телефон на сайте = в картах.

### C3. Платный трафик (поддержка SEO)

Пока органика слабая — не конкурировать бюджетом за весь рынок:

- **Яндекс.Директ / Google Ads:** только бренд + 3–5 коммерческих («крашеная вагонка Москва», «крашеный планкен купить») с посадочными после правок meta.
- Ретаргет посетителей каталога/квиза.
- Не лить на сырые дубли блога.

### C4. Контент-пайплайн (уже в репо)

Инфраструктура готова: thruuu-брифы → агенты writer/humanizer/linker → `drafts/`.

Ритм: **2 SEO-статьи в неделю** по очереди B3, плюс 1 обновление коммерческого лендинга.  
Перед написанием: `python3 scripts/gsc_export.py` → читать `knowledge/gsc/`.

## 11. Итог

Сайт уже индексируется и держит бренд, но **не конвертирует коммерческий спрос**: слабые сниппеты, дубли блога, размытая URL-архитектура и отставание от конкурентов по офферу (цена, сроки, посадочные).  

План: сначала выжать CTR и чистоту индекса на WP, параллельно переписать контент по кластерам, затем переехать на Next.js **только с жёсткой картой 301**. Продвижение — локаль (Истра/Москва), Яндекс, точечные ссылки и стабильный контент-пайплайн 2 статьи/неделю.
