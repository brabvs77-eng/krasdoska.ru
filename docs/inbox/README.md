# Временная папка для файлов

Сюда можно загружать файлы для анализа агентом Cursor.

## Как использовать

1. Положите файл в эту папку (`docs/inbox/`).
2. Закоммитьте и запушьте в GitHub.
3. Напишите агенту: «проанализируй `docs/inbox/имя-файла`».

## Важно

- Папка **временная** — после обработки файлы лучше удалять.
- Не храните здесь пароли, ключи и персональные данные.
- Большие бинарники (>10 МБ) удобнее прикреплять прямо в чат Cursor.
